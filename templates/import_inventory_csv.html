CSV File Format Instructions

Please ensure your CSV file has the following columns in this order: Barcode, Name, Quantity.

  • The first row of the CSV file **must be the header row** exactly matching: Barcode,Name,Quantity.
  • Barcode: Required. Used to identify items.
  • Name: Required. The name of the item.
  • Quantity: Required. Must be a non-negative whole number.

Import Strategy:

  • If an item with a matching 'Barcode' exists in the inventory, its 'Name' and 'Quantity' will be updated with the values from the CSV.
  • If an item with a 'Barcode' from the CSV does not exist, it will be added as a new item.
  • The 'Last Updated' field will be automatically set by the system upon import/update.
