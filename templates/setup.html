Setup Instructions

To configure the application, you need to:

  1. Create a Google Cloud Platform (GCP) Project (or use an existing one).
  2. Enable the Google Sheets API for your project.
    • In GCP Console: APIs & Services → Library → Search "Google Sheets API" → Enable.
  3. Create a Service Account:
    • In GCP Console: APIs & Services → Credentials → + CREATE CREDENTIALS → Service account.
    • Give it a name (e.g., "inventory-app-scanner"). Click "CREATE AND CONTINUE", then "DONE" (roles can be minimal for now).
  4. Generate a JSON Key for the Service Account:
    • Click on your new service account → KEYS tab → ADD KEY → Create new key → Select JSON → CREATE.
    • A JSON file will download. Open this file and copy its entire content into the "Service Account JSON Key Content" field on the setup page.
  5. Create a Google Sheet:
    • Go to Google Sheets and create a new blank spreadsheet (e.g., name it "WebAppInventory").
    • The Google Sheet ID is part of its URL: https://docs.google.com/spreadsheets/d/SHEET_ID_HERE/edit. Copy this ID into the "Google Sheet ID" field.
  6. Share the Google Sheet with the Service Account:
    • In your Google Sheet, click "Share" (top right).
    • Find the client_email address in the JSON key content you copied (it looks like your-service-account-name@your-project-id.iam.gserviceaccount.com).
    • Paste this email into the "Add people or groups" field, give it Editor permissions, and click "Send" (uncheck "Notify people" if desired).

Once you have the Sheet ID and the JSON key content, paste them into the respective fields on the setup page and click "Save Configuration".
